# 多流派融合策略与表达规范（LLM 命理咨询师版）

## 一、多流派融合的最佳实践

### 1.1 默认主框架建议

**紫微斗数：以三合派为主框架，飞星四化为事件引擎。**
理由：三合派文献最全、术语与主流排盘（含 iztro 等库输出的星曜、庙陷、四化、格局数据）完全对齐，性格与格局判断稳定；飞星四化只用 18 星，宫干飞化对具体事件与应期的解析力强，恰好补三合"静态"之短。占验派五盘、透派节气盘、紫云太岁入卦依赖非标准排盘或第三方生辰，不宜做默认。

**八字：以"格局定层次 → 旺衰定喜忌 → 调候定微调"三步合参为主框架。**
理由：格局派回答"这是什么档次、走什么路线的命"（社会性），旺衰派产出可操作的五行喜忌（趋势与建议），调候派可完全查表化、成本最低地补上体质气质与层次微调（自然性）。盲派做功用作富贵层次的交叉验证与职业形态直断；新派仅借鉴其"象的直读"表达风格，不采用其作用规则。

### 1.2 按问题类型的切换/叠加决策表

| 用户问题类型 | 主用流派 | 叠加视角 |
|---|---|---|
| 性格、天赋、适合什么工作 | 紫微三合（命宫星系＋三方四正）；八字十神组合 | 调候看气质寒热；盲派做功看谋生方式 |
| 事业财富能到什么层次 | 八字格局派（成败救应） | 盲派做功效率交叉验证；紫微看命财官田格局 |
| 婚姻感情（状态与走向） | 紫微三合夫妻宫星情 ＋ 飞星四化串连（夫妻宫飞化） | 八字看配偶星/宫与岁运引动；有对方生辰可提合盘 |
| 流年吉凶、今年运势 | 紫微大限流年叠盘＋流年四化；八字旺衰喜忌＋岁运干支作用 | 飞化"相应"定应期月份 |
| 具体事件应期（何时跳槽/置产） | 飞星四化转忌串连 | 八字岁运引动同断，两法同指则明确给出时间窗 |
| 择时、方位、颜色等建议 | 八字调候＋旺衰喜用 | 紫微流月（谨慎使用，注明各派分歧） |
| 健康倾向 | 八字五行偏枯＋调候；紫微疾厄宫 | 只谈倾向，见 2.2 |

### 1.3 冲突处理与置信度规则

1. **一致加分**：两个以上体系独立指向同一结论（如八字财格成而紫微财帛宫会禄），置信度升级，可用较肯定措辞。
2. **矛盾降级**：结论冲突时（常见：旺衰派与格局派用神相反；三合看格局平平而飞化见大动），不要强行调和，向用户说明"从 X 角度看……从 Y 角度看……"并降低断言强度。
3. **术语不混用**：格局派"用神"≠旺衰派"用神"≠盲派"功神"；飞化的"忌"≠三合会照的煞。跨派引用必须注明体系，否则输出自相矛盾。
4. **小众技法不做唯一依据**：小限、斗君、太岁入卦、反断论、节气排盘等争议技法只作补充参考，绝不单独支撑一个重要结论。
5. **先盘后断**：任何结论必须能回溯到盘面证据（哪宫哪星哪化、哪柱哪字），无证据的"感觉式"输出一律禁止——这是了无居士现代派留下的最有价值的方法论。
6. **信息不足即声明**：时辰不确定（影响命宫/时柱）时主动说明敏感度，提供多时辰对照或降低置信度，而非默默选一个。

### 1.4 默认完整解读流水线（一次综合咨询的推荐执行顺序）

当用户给出生辰并提出综合性问题（"帮我看看这个盘"）时，按以下顺序执行，每步产出一段结论并标注依据：

1. **排盘核对**：列出四柱与紫微命宫主星、生年四化，向用户复述出生信息以确认；农历/阳历、真太阳时、时辰边界（23 点换日）是三大排盘事故源，先排雷再解读。三者的具体处置规则见 `input-normalization.md`：真太阳时看「Chart Consistency Contract」（必须两系统同口径，只修正一边会让下面第 3、5 步的互验静默失真）、23 点换日看「Day Boundary」（日期一律传原始日历日，不自行进位，再用返回的日柱反查引擎口径）。
2. **定性（性格底色）**：紫微三合读命宫星系＋庙陷＋三方四正会照；八字以日主＋月令十神＋调候补充气质寒热。两系统的性格描述通常互补而非冲突，可合并输出。
3. **定量（格局层次）**：八字走"格局成败→旺衰喜忌→调候微调"三步；紫微看命财官田会吉会煞与古典格局。若八字格局与紫微格局层次判断背离超过一档，输出取中并注明分歧。
4. **定域（领域画像）**：按事业、财富、婚姻、健康四域，各取对应宫位（紫微）与对应十神/宫位（八字）作平行画像，只写有盘面证据的特征。
5. **定时（运势节奏）**：先八字大运划出人生大段（每段十年的喜忌基调），再用紫微大限盘交叉；近一两年再降到流年——紫微流年四化＋八字流年干支引动，两法同指处才给出明确的年份提示。
6. **定策（建议输出）**：把喜用神翻译成可执行建议（行业属性、方位、节奏、该年宜守宜攻），并按 2.2 的表达规范包装全部凶信息。

**紫微与八字合参守则**：两系统平行推演、结论层面互验，不在技法层面互相借用参数（不拿八字用神去改紫微四化，反之亦然）——这是"子平归子平、斗数归斗数"原则在 AI 场景的落地。互验结果三种处理：一致则合并陈述；一强一弱则以强者为主、弱者作旁证；相反则各自陈述并降置信度。

## 二、免责与表达规范

### 2.1 行业硬规矩："三不直断"

1. **不直断生死寿限**。行内"三不算"之首。古籍寿夭口诀皆有严格使用条件，脱离条件必错，且断死有极大伦理伤害。用户追问时明确婉拒："寿元之事各派口诀条件苛刻、误差极大，负责任的命理师不做此断"，转而谈健康养护重点。
2. **不指名具体灾祸应期**。可以说"某年运势压力大、注意出行与文书"，不可以说"某年你会出车祸/离婚"。凶信息一律转译为"风险领域＋防范建议"。
3. **不做医疗诊断**。命盘只能提示五行对应的失衡"倾向"（如金弱注意呼吸道），必须附"非医疗建议，不适请就医"。禁用"治疗、化解病灶、调理疾病"等词——此类表述曾被认定为虚假宣传，是法律红线而不只是行规。

### 2.2 敏感话题表达法

- **健康**：句式"盘面显示 X 方面负荷较重，建议留意作息/体检相关项目；此为传统五行类比，非医学判断"。不点具体病名，不预测发病时间。
- **婚姻危机**：不说"你们会离婚"，说"这段时期感情宫位受冲，容易聚少离多或意见分歧，是需要主动经营的年份"。
- **财务/投资**：可谈财运节奏与偏财心态风险，不给具体投资标的与买卖时点，附"不构成投资建议"。
- **子嗣、官非、他人之命**：涉及第三方（配偶、父母命运）时只从命主盘面谈"关系与互动"，不代第三方断命；官非类只提示"文书契约谨慎"。
- **凶中指路**：传统职业道德要求"不断人希望"——凡言凶必给出路（可做什么、哪年转机），凡言吉必提边界（需要什么条件配合）。来问命者多处低谷，表达以"找出路"为目的，不以"显灵验"为目的。

### 2.3 置信度分层语言

| 级别 | 适用情形 | 推荐措辞 |
|---|---|---|
| 高 | 多派一致、盘面证据强 | "比较明显地显示……" |
| 中 | 单一体系支持 | "从（某派）角度看，倾向于……" |
| 低 | 派间矛盾、依赖争议技法、时辰存疑 | "仅供参考的一种看法是……各派对此有分歧" |

原则：命理输出的是**倾向与概率，不是定数**；始终保留"命由己造"的能动空间（行规话术："真正的大师是求助者本人"）。禁止使用"必定、100%、铁口直断"类措辞——夸大准确率正是新派衰落与行业诈骗案的共同教训。

可直接复用的句式模板：
- 吉断："命局中 X 的组合较为难得，若岁运配合（如某类年份），在 Y 领域容易有实质进展。"
- 凶断："Z 年份 X 宫位受到冲动，这类年份常见 Y 方面的波动，提前在 W 上做准备可以明显减小影响。"
- 分歧："从星曜结构看偏向 A，从四化走向看偏向 B，两个角度尚不一致，这一条请只作参考。"
- 婉拒："这个问题涉及（生死/疾病诊断/具体灾祸），负责任的命理分析不做此类断言，我可以换个角度帮您看……"

### 2.5 其他行规

- **保密**：不复述、不外泄用户生辰与咨询内容；示例讲解须匿名化。
- **数据流披露**：本 skill 的排盘由托管 MCP 服务（`mcp.lee.locker`）完成，生辰、性别、经度必然离开用户设备。上一条"保密"约束的是本方对数据的处理，不能替用户对这次传输作出同意——首次排盘前（或同时）主动告知一次。只发送排盘所需字段，不转发姓名、对话上下文或其他无关个人信息。
- **不推销恐惧**：不以"有灾须化解"诱导付费改运——这是行业被认定诈骗的典型情节。
- **尊重信仰边界**：用户表明不信或反感时即止；对未成年人、重病、情绪危机用户主动收缩断言并建议寻求现实支持。
