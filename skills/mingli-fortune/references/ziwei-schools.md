# 紫微斗数主要流派解读手册（LLM 参考版）

> 总体格局：斗数分两大主流——**南派重星曜**（三合派、中州派，用全星系几十至上百颗星），**北派重四化**（飞星派、四化派、河洛派，只用 16–18 颗星）。港澳以中州派为主流，台湾四化飞星兴盛，大陆以三合为主。任何流派论命都应"宫位、星曜、四化"三位一体，不可只凭单一要素下结论。

## 一、三合派（星曜派，含中州派）

三合派是传播最广的传统主流；中州派由王亭之公开传授后成名，以十四主星组成的六十星系互涉为骨架（另有陆斌兆《紫微闡微》一支）。

### 核心理论
靠**星曜本质 + 庙旺利陷 + 三方四正会照 + 格局**判断。全星系排盘（甲级星约 32 颗、乙级 34 颗，另有丙丁戊级星）。每宫吉凶不单看本宫，必看其三方四正（本宫、对宫、三合两宫）共四个宫位会入的星曜组合；生年四化只作吉凶增减的修饰。中州派进一步以"星系互涉"推理：某星系遇另一星系必产生特定变化，论命法则即从变化中推衍。

### 解读步骤
1. 排盘：定命宫身宫、五行局，安全部星曜，标庙旺利陷。
2. 看命宫主星组合与亮度，定性格底色与先天禀赋（如紫微天府主稳重领导、杀破狼主开创波动、机月同梁主稳定文职）。
3. 看命宫三方四正（命—官禄—财帛—迁移）会照的吉星（左辅右弼、文昌文曲、天魁天钺、禄存天马）与煞星（擎羊陀罗、火星铃星、地空地劫），定格局高低（如君臣庆会、日月并明、火贪格、羊陀夹忌）。
4. 加入生年四化：禄权科入三方主加分，忌入命财官田主该领域有亏欠。
5. 依次分析十二宫，每宫用它自己的三方四正（如看疾厄兼看父母、兄弟；看夫妻兼看官禄、迁移、福德）。
6. 大限盘叠本命盘，流年再叠大限，星曜吉凶层层叠加论运。

### 特色技法
- **格局定性法**：背熟数十个古典格局（府相朝垣、阳梁昌禄、铃昌陀武等）快速给出层次判断。
- **六十星系互涉**（中州派）：同一主星在不同宫位与不同辅佐煞曜同度，性质完全改写，须整组推理。
- **借宫安星、转宫立太极**（王亭之）：对宫无主星时借对宫星曜，并可把任一宫当作"命宫"重设三方四正细论该宫之事。
- **煞星双面性**：煞星会照吉星或落庙旺可转为激发力（如火贪为暴发格）。

### 擅长领域
性格与天赋、人生总格局与富贵层次、职业方向、六亲关系底色、大限十年趋势。属"静态油画"式解读，善断大方向。

### 局限与争议
星曜太多、组合复杂，易流于逐星罗列而无结论；对具体事件与应期的精度低于四化派。中州派"每代单传自白玉蟾"的师承被广泛质疑为托古。各家庙旺表不一，中州派庚、戊、壬干四化与通行版本不同（如庚干天同化忌 vs 天相化忌），跨派对盘会得出矛盾结论。

## 二、飞星四化派（含梁派飞星、钦天门）

北派主力。钦天门传自素心老人，秘笈《钦天四化紫微斗数飞星秘仪》；梁若瑜承周清河一脉自成"梁派飞星"，是当代传播最广的飞星体系。

### 核心理论
只用 18 星（十四主星＋左右昌曲），**以宫位为主轴、四化为用神**。核心机制是"宫干飞化"：任一宫的天干按十干四化飞出禄权科忌到另一宫，形成两宫重叠，读作"A 宫对 B 宫做某事"（如官禄宫化禄入田宅＝想开店做生意）。禄主缘分与得到、权主掌控与扩张、科主缓和与贵人、忌主亏欠、执着与损耗。星曜只作补充定性。钦天门另立**来因宫**（生年天干所在宫）为生年四化的发射源，是此生因果功课的来源。

### 解读步骤
1. 定生年四化落宫：这是先天定数，禄=此生之缘、忌=此生之债，看忌入我宫（命兄夫子财疾）还是他宫。
2. （钦天）定来因宫，生年四化的落点须回到来因宫解释原因。
3. 查十二宫**自化**（宫干四化回到本宫）：离心自化主漏失、留不住；解象次序为先生年四化、再向心自化、后离心自化。
4. 以命宫、疾厄、福德等宫干飞化，看命主意愿与身心走向。
5. 用**忌转忌、禄转忌串连**追事件因果链：A 宫化忌入 B 宫，再以 B 宫宫干化忌入 C 宫，串出"因—过程—果"（如夫妻禄入福德、转忌入疾厄冲父母，为婚变显象之一）。
6. 论运：流年命宫四化"走天下"，飞化与生年四化产生"相应"处即为应期。

### 特色技法
- **自化**：无生年四化而自化为虚耗；有生年四化又自化（如生年禄遇离心忌）为"禄随忌走"，得而复失。
- **转忌串连**：禄转忌看福报最终落点，忌转忌看灾损传导路径，是断具体事件的主武器。
- **来因宫十二因缘**（钦天）：来因在命宫为自立格、在田宅重家庭等，用于定此生主轴。
- **忌的量化**：单忌坐守辛劳而安稳，双忌以上冲激则动荡破败；田宅三方（田宅、兄弟、疾厄）为收藏宫，被冲最忌。

### 擅长领域
具体事件与应期（何时结婚、破财、换工作）、婚姻财运的事件级判断、因果链条解释、择时。属"动态影片"式解读。

### 局限与争议
星情弱化严重，被三合派批评"18 星论天下"失之粗疏；飞化一象多义（官禄化禄入田宅可以是开店、也可以是买办公室），无星情约束时易过度解读。各家飞化规则（如何时用转忌、自化是否有效）互不兼容；实践者提醒必须回看星曜本性（财星化忌先伤财帛）才可靠。

## 三、河洛派

由台湾方外人（曾国雄）所创，四化派系中以验证性著称的一支，资料集结为《中国绝学》系列。

### 核心理论
**以化忌为立论基础，用河洛数理配宫**。河图为体（先天格局）、洛书为用（后天时运）；宫位按"一六共宗（命—疾厄）、二七同道（兄弟—迁移）、三八为朋（夫妻—交友）、四九为友（子女—官禄）、五十同途（财帛—田宅）"结成数理对。最核心概念是**气数位**：任一宫逆数第九位（命宫的气数位即官禄宫），以气数位宫干所化禄权科忌应本宫吉凶。用星仅 18 颗。

### 解读步骤
1. 星情断吉凶、四化断契机、卦位断人事，三层并用。
2. 命宫宫干四化看心态行为；官禄宫（命之气数位）宫干四化审吉凶祸福。
3. 划分我宫（命、兄、财、疾、官、田）与他宫（夫、子、迁、友、福、父）：他宫禄入我宫为我得，我宫禄入他宫为我失。
4. 查化忌与生数宫：命、财、官、田为生数宫，忌入为收藏归我（吉），忌冲为"破体"损失（凶）。
5. 论运层级规则：上一级盘四化落入下一级盘只"审迹象"，下一级盘四化入上一级盘才"断吉凶"；先审迹象，后断吉凶。

### 特色技法
- **气数位断事**：看任何宫先看其逆数第九位的四化，此为该宫成败之枢纽。
- **断行业**：以财帛宫（官禄之气数位）天干四化、按忌→禄→权→科顺序看落宫落星定行业。
- **忌出/忌入**：忌入生数宫为归藏，忌冲生数宫为破耗，一字之差吉凶反转。
- **禄忌因果观**：化禄为起因（欲望），化忌为结果（执着），首尾相扣断一事始末。

### 擅长领域
财运进退、行业选择、事件吉凶契机、流运层级判断。

### 局限与争议
传承面窄、教材以函授手稿流传，系统性弱；规则记忆量大（每宫都有自己的气数位、命迁线、父疾线）；与梁派飞星共享宫干飞化但细则相左（如吉凶判断层级），混学易乱。

## 四、占验派

代表人物为天乙上人（自称占验法门第五十四代），著《现代斗数真诀》《占验紫微 PMP》等；台湾一系今由范振木等传承，晚年另创图像化的"东方星理学"。

### 核心理论
**杂糅式实证**：以传统星情格局为底，融合奇门遁甲的卦位人事，加上飞星派的十二宫飞化，凡验者皆收。断运用**五盘并断**：本命、大限、小限、太岁（流年）、斗君（流月基准）五盘互参。

### 解读步骤
1. 本命盘以星情格局定命格层次（同三合派）。
2. 大限盘看十年趋势，小限盘看本身年运。
3. 太岁盘看当年外来因素；太岁流月主外来、小限流月主自身运程，内外分论。
4. 由斗君落宫起正月，以该宫干支起四化，逐月化该宫为流月命垣断月运。
5. 五盘吉凶叠加：某宫凶而大小限、太岁又凶，其年灾病官非难免；再以飞化定契机。

### 特色技法
- **五盘叠断**：比通行"三盘"（本命/大限/流年）多小限与斗君两层，应期定位更细。
- **斗君定流月**：斗君所在宫吉则一年吉，并作流月推演的起点。
- **小限四化预警**：小限四化与羊陀所落宫位，斗君流月逢之须特别留意。

### 擅长领域
流年流月吉凶、应期推算、灾病官非等时点性预警。

### 局限与争议
体系庞杂、门内完整技法不公开（主要在天乙上人著作内），学习成本高；"五十四代传承"无从稽考；小限、斗君在现代主流（尤其飞星派与部分三合家）中已被弃用，各派对其有效性分歧极大。

## 五、透派（明澄派）

张耀文于 1960 年代将其携往日本、再回流台湾，自称十三代传人，创始者"明代梅素香"之说无从稽考。

### 核心理论
框架与《全书》古籍大同小异，但三点独异：**命身宫安法与古本不同、命盘不安宫干**（故无宫干飞化）、**排盘要过节气**（以节气而非农历月定月份，向子平靠拢）。星曜解读采用**封神演义人物类象**：每星对应一位封神人物（天机＝姜子牙主智谋、武曲＝周武王主武勇富足），以人物性格故事直观释星。

### 解读步骤
1. 依节气定月份后排盘，按透派法安命身宫。
2. 以封神人物类象读命宫及各宫主星，得出人格与人事画像。
3. 按三方四正与生年四化论格局吉凶（无飞宫技法）。
4. 与子平八字合参互验（透派兼传子平、六壬、奇门）。

### 特色技法
- **节气排盘**：同一人在透派与通行派可能得出不同命盘。
- **封神类象记星法**：把抽象星性转成人物叙事，解释性格极为形象。
- **五术并用**：命（紫微＋子平）、卜（六壬）、相、医、山互参，是"五术"分类的来源门派。

### 擅长领域
性格画像与人物式描述、紫微与八字互验的综合判断。

### 局限与争议
过节气排的命盘被后来研究者发现"许多时候不准确，故多弃之不用"，流派因此式微；无宫干飞化使其难断细事；门派历史真实性是斗数界公认的疑案。**注意：LLM 不应默认用透派排盘规则，与主流盘不兼容。**

## 六、紫云派

紫云师承何茂松，穷三十年实证自成一派，首开长篇实例论命的"传记命学"，著《斗数论姻缘》《斗数论求财》等十余种。

### 核心理论
理论基石是传统三合派（星情＋三方四正），其上自创三大技法：**太岁入卦法**（把与命主有密切互动之人的生年干支"输入"命主盘上论互动吉凶）、**三代论**（以父母、子女之盘验证与细化本人盘）、**太岁宫位**。解决的核心问题是"同盘不同命"的个别差异。

### 解读步骤
1. 先按三合派完成本命、大限的常规分析。
2. 就所问议题组"宫位网"：如问感情须本命、本命夫妻宫、大限、大限夫妻宫四宫起看，绝不单宫论断。
3. 太岁入卦：取对方生年干的四化（另输禄存羊陀、魁钺，感情加红鸾天喜）入命主盘看落宫，断双方关系走向；取对方生年支在盘中的宫位，看该宫星情断对方个性。
4. 以三代人之盘交叉验证（父母宫、子女宫与实际亲属盘互证），修正判断。

### 特色技法
- **太岁入卦四原则**：入卦对象须与命主密切互动；互动越密越准；同年次不同角色则基础宫位不同；同年次同角色以南斗为男、北斗为女区分。
- **应用面广**：不限感情，合伙人、上司下属皆可入卦。
- **传记式实证**：以数十年追踪的真实命例反推规则，重个案脉络而非条文。

### 擅长领域
人际互动（婚恋、合伙、上下级）、同盘差异辨析、六亲课题。

### 局限与争议
太岁入卦依赖取得他人生辰，AI 场景常不可得；技法来源有"自创"与"借飞星派秘传改良"两说；判断高度依赖论者经验，条文化程度低，难以机械复制。

## 七、现代改良派（了无居士等）

了无居士（黄忠霖）出自紫云门下而自立，1985 年起与许兴智等出版《现代紫微》七集，掀起斗数"科学化"运动。

### 核心理论
不以新技法立派，而以**逻辑实证与纯化**立场立派：反对"紫平合参"（主张子平归子平、斗数归斗数），拒绝神煞、关煞混入斗数；一切规则须经命例验证，能证伪者弃之。主张精要尽在古籍，热衷评注甄别古籍条文的真伪与适用条件。

### 解读步骤
1. 排通行盘，只采用经过验证的星曜、四化规则，剔除神煞。
2. 对每一判断先陈述依据（何星何宫何化），再给结论——"可追溯"是底线。
3. 以假设—验证方式论命：先提出可检验的推断，与命主已发生事实核对校准后，再推未来。
4. 表达上采概率化、留有余地的语言，反对铁口直断。

### 特色技法
- **古籍批判性评注**：逐条辨析《全书》《全集》条文的适用条件与讹误。
- **大师祛魅**：以公开论证检验各家宣称（《紫微论命》即批判当时"大师"著作），建立方法论自觉。
- **命例统计意识**：以多命例归纳代替孤证。

### 擅长领域
教学与观念纠偏、心理咨询式的理性论命、跨派规则的真伪鉴别。是 AI 命理师在方法论与表达层面最值得继承的一派。

### 局限与争议
"能破不能立"——批判体系完整但自身技法建树有限，有评者称其书"有可读性、现实性，却无实际意义"；引发的论战伴随大量人身攻击。其"去神煞"主张也未被全行业接受。
